SAYWARD startup stability rebuild

Runtime files use fixed filenames.
Architecture:
- index.html is now the only real entry page.
- sayward-app.html is only a redirect stub for old restored tabs/bookmarks.
- CSS is loaded sequentially after the boot screen paints.
- Vocabulary JS parts, core runtime, and patches are executed sequentially in the same page.
- No prefetch-then-navigation step.
- No service worker/cache deletion.
- The accidental full recursive decode of UNIFIED_WORDS at cold start was removed.
- Repeated visual-only boot rescans were reduced.
- Boot stage/errors are recorded in localStorage keys sayward_boot_last and sayward_boot_error.
