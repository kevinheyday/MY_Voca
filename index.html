📘 MY VOCA 사용방법

이번 업데이트: 홈 상단의 MY VOCA, 오늘의 학습, 학습 재생 설정 영역을 모바일 화면에 맞게 압축했습니다. 기능은 그대로 유지되며 첫 화면에서 DAY별 학습 영역을 더 빠르게 확인할 수 있습니다.

⭐ DAY 시작 전 모르는 단어 선택
홈에서 DAY 카드를 눌렀을 때 해당 DAY의 모르는 단어가 0개이면 안내 팝업이 표시됩니다. 모르는 단어 선택에서 헷갈리거나 다시 볼 단어를 최소 1개 표시하면 이후 모르는 단어만, 틀린 단어만, 틀린 단어 + 모르는 단어 집중 학습을 바로 사용할 수 있습니다. 이미 모르는 단어가 1개 이상 저장된 DAY에서는 이 팝업이 다시 뜨지 않습니다.
1. 처음 시작할 때
  1. 홈에서 공부할 DAY를 선택합니다.
  2. 퀴즈의 모르는 단어 선택에서 전체 단어와 뜻을 먼저 훑어봅니다.
  3. 모르는 단어를 체크하면 학습 화면의 모르는 단어와 자동으로 연동됩니다.
  4. 홈에서 전체 반복 또는 틀린 단어 + 모르는 단어를 선택해 학습을 시작합니다.
DAY 선택→모르는 단어 선택→모르는 단어→반복 학습
2. 홈 화면과 반복 학습
전체 반복선택한 DAY의 모든 단어를 연속 학습합니다.
틀린 단어만퀴즈에서 한 번 이상 틀린 단어만 재생합니다.
모르는 단어직접 표시한 모르는 단어만 재생합니다.
틀린 단어 + 모르는 단어두 목록을 합쳐 중복 없이 재생합니다.
기본 순서DAY와 단어 번호 순서대로 학습합니다.
랜덤저장된 랜덤 순서를 유지해 중단 지점부터 이어서 학습합니다.
여러 DAY를 공부하다 앱을 닫아도 마지막 학습 DAY가 새 선택 범위에 포함되면 저장 위치부터 이어집니다.
3. 학습 화면 사용법

읽기 순서: 단어 → 뜻 → 첫 예문 → 패러프레이징 → 회화 패턴 → Collocation → 유의어·반의어

패러프레이징의 사용된 유의어: 패러프레이징 문장에 실제로 들어간 표현만 파란색으로 강조하고 영어 표현 - 한국어 뜻으로 표시합니다. 원문 단어가 그대로 유지되거나 등록된 유의어가 문장에 없으면 배지를 표시하지 않습니다.

유의어·반의어 목록: 각 표현은 영어 단어 - 한국어 뜻 형식으로 표시됩니다. 🔊 버튼을 누르면 영어 표현을 들을 수 있습니다.

  • 🏠 홈: 음성·자동 스크롤·반복을 즉시 중지하고 홈으로 이동합니다.
  • ☆ 모르는 단어: 현재 단어를 바로 등록하거나 해제합니다.
  • ⏸ 재생 정지 / ▶ 재생 시작: 현재 카드 위치를 유지한 채 음성을 멈추거나 다시 시작합니다.
  • 좌우 스와이프: 이전·다음 단어로 이동합니다.
4. 퀴즈 4가지
  • 학습 조건 동기화: Drawer의 모르는 단어·틀린 단어·틀린 단어 + 모르는 단어를 선택하면 DAY 위 학습 범위와 퀴즈 대상 콤보박스에도 즉시 반영됩니다. 어느 콤보박스에서 변경해도 다른 화면에 같은 조건이 저장됩니다.
  • 퀴즈 대상 조건: 전체 단어·틀린 단어만·모르는 단어·틀린 단어 + 모르는 단어 중 하나를 선택하면 모든 퀴즈 방식에 같은 조건이 적용됩니다.
  • 퀴즈 하단 버튼: 왼쪽부터 다음·이전·자동 넘기기 순서입니다. 자동 넘기기 ON이면 정답·오답 후 단어와 예문을 끝까지 읽고 다음 문제로 이동합니다. OFF이면 자동 음성과 자동 이동이 멈추며 다음 버튼으로 직접 진행합니다.
  • 기존 객관식: 자동 재생이 켜져 있으면 정답 선택 후 정답 단어와 예문을 끝까지 들은 뒤 다음 문제로 이동합니다.
  • 단어 말하기: 영어 또는 뜻을 보고 답을 소리 내어 말한 뒤 맞았어요·오답을 선택합니다. 정답을 열면 영어 예문 아래에 한글 해석도 함께 표시됩니다. 자동 재생이 켜져 있으면 정답 단어와 영어 예문을 읽고 이동합니다.
  • 문장 말하기: 한글 뜻 → 전체 문장 → 핵심 빈칸 → 전체 문장 말하기 순서로 기본·패러프레이징 문장을 연습합니다. 최종 채점 후 자동 재생을 시작하거나 정지할 수 있습니다.
  • 모르는 단어 선택: 선택한 조건에 해당하는 단어 목록에서 모르는 단어를 한꺼번에 관리합니다. 전체 DAY를 확인하려면 퀴즈 대상을 ‘전체 단어’로 선택하세요.
  • 유의어·반의어: 같은 뜻 찾기, 유의어 뜻 맞추기, 패러프레이징 문장에 사용된 유의어 찾기, 반의어 찾기를 섞어서 출제합니다. 뜻이 확인된 유의어만 문제로 사용하므로 ‘등록된 뜻이 없습니다.’ 선택지는 표시되지 않습니다. 등록된 데이터가 있는 단어만 문제로 나오며 결과는 해당 학습 단어의 퀴즈 통계와 망각곡선에 반영됩니다.
문제를 풀지 않아도 다음 문제로 건너뛸 수 있으며, 건너뛴 문제는 정답·오답 통계에 포함되지 않습니다.
5. 망각곡선과 스코어
망각곡선은 학습 화면의 임의 버튼이 아니라 퀴즈 정답·오답 결과를 기준으로 계산됩니다. 오답은 빠르게 다시 복습 대상으로 들어가고, 연속 정답이 쌓이면 복습 간격이 점차 길어집니다. 스코어 화면에서는 DAY별 정답률과 취약 단어를 확인할 수 있습니다.

🔊 학습 모드 음성 설정
읽기 속도와 학습 반복 설정을 한곳에서 관리합니다. 예문·패턴·Collocation·유의어 반복 횟수, 단어만 읽기 횟수, 연속 재생 학습 횟수를 같은 섹션에서 설정할 수 있으며 각 값은 서로 독립적으로 적용됩니다.
⚙ 단어 읽기와 연속 학습 횟수
단어만 읽기 횟수와 연속 재생 학습 횟수는 서로 독립적으로 설정됩니다. 기본값은 각각 3회와 1회입니다. 단어 읽기 횟수는 한 카드에서 영어 단어와 한글 뜻을 읽는 횟수이고, 연속 학습 횟수는 선택한 DAY 전체를 처음부터 끝까지 반복하는 회수입니다.
🔤 단어 읽기 모드
홈의 자동 읽기 범위에서 단어 읽기를 선택하면 각 카드에서 영어 단어 → 한글 뜻만 Config에서 지정한 횟수만큼 읽고 다음 단어로 이동합니다. 이 상태에서 현재 단어를 누르면 영어 단어와 한글 뜻을 제한 없이 반복합니다. 반복 종료 방식은 선택 학습과 일반 DAY 학습의 규칙을 그대로 따릅니다.
🔁 현재 단어 반복
DAY별 선택 학습 중에는 현재 단어를 제한 없이 반복합니다. 반복 종료를 누르면 현재 읽기를 끝까지 마친 뒤 다음 단어부터 전체 반복 학습을 자연스럽게 이어갑니다.

일반 DAY 학습 중에는 현재 단어만 제한 없이 반복합니다. 반복 종료를 누르면 현재 읽기를 끝까지 마친 뒤 그 자리에서 정지합니다.
📝 퀴즈 조작과 음성 설정
Config의 퀴즈 단어 읽기 횟수에서 1~5회를 선택할 수 있습니다. 퀴즈 화면에서는 왼쪽으로 밀면 다음 문제, 오른쪽으로 밀면 이전 문제로 이동합니다. ☰ 메뉴는 학습·퀴즈·스코어·망각곡선 등 주요 화면에서 언제든 사용할 수 있습니다.
🎧 Day Loop Training 사용법
Day Loop Training은 실전 문장 말하기의 마지막 문장까지 학습하면 자동으로 시작됩니다. 해당 Day의 모든 실전 문장을 2단계와 동일하게 50% 이상 가린 상태로 한 화면에 보여주고, 완전한 영어 문장을 반복해서 들려줍니다.

① 전체 반복
Config의 Day Loop 문장당 반복 횟수에서 1회 / 2회 / 3회 / 5회 중 선택할 수 있습니다. 예를 들어 2회로 설정하면 Sentence 1을 2회 → Sentence 2를 2회 → Sentence 3을 2회 순서로 진행하고, 마지막 문장이 끝나면 다시 Sentence 1부터 반복합니다.

② Sentence N ∞ 집중 반복
각 카드의 Sentence N ∞ 버튼을 누르면 해당 문장만 무한 반복합니다. 다른 문장의 Sentence 버튼을 누르면 기존 집중 반복은 자동으로 해제되고 새로 선택한 문장으로 즉시 이동합니다. 현재 집중 반복 중인 같은 버튼을 다시 누르면 집중 반복을 해제하고 다음 문장부터 기존 전체 Loop를 자동으로 이어갑니다.

③ 문장 보기 / 숨기기
각 Sentence 버튼 옆의 👁 문장 보기를 누르면 그 카드의 영어 문장만 전체 문장으로 표시됩니다. 버튼은 🙈 문장 숨기기로 바뀌며, 다시 누르면 2단계처럼 50% 이상 가린 문장으로 돌아갑니다. 이 기능은 화면 표시만 변경하므로 일반 반복 중이거나 집중 무한 반복 중에도 음성은 중단되지 않습니다.

④ 반복 듣기 ON / OFF
상단의 반복 듣기 OFF를 누르면 현재 음성이 즉시 정지합니다. 다시 ON 하면 Day Loop를 다시 시작할 수 있습니다. 학습·퀴즈·홈 등 다른 화면으로 이동할 때도 Day Loop 음성은 자동으로 종료됩니다.

추가 실전 패턴
실전 문장에는 Day에서 직접 학습한 패턴 외에도 실제 회화에서 재사용 가치가 높은 표현이 포함될 수 있습니다. 이런 표현은 보라색으로 표시되며, 문장 아래의 추가 실전 패턴에서 기준 영어 패턴과 한글 뜻을 확인할 수 있습니다.

추천 학습 순서
한글 문장을 먼저 보고 영어 문장을 떠올린 뒤, 아래의 50% 가린 영어 문장으로 확인하고 정답 음성을 들으세요. 한글과 영어 모두 학습 단어는 파랑, 학습 패턴은 분홍, 추가 패턴은 보라색으로 표시됩니다. 한글 패턴은 ~ 또는 ... 자리에 들어가는 내용 전체를 칠하지 않고, 실제로 재사용되는 고정 문형 부분만 색칠합니다. 2단계와 Day Loop의 빈칸도 같은 색 규칙을 사용하며, 어느 항목에도 속하지 않는 일반 빈칸은 검정 테두리로 표시됩니다. 그다음, 막히는 문장은 Sentence N ∞로 집중 반복하세요. 필요할 때만 문장 보기로 정답을 확인하고 다시 숨기면 Recall 연습을 계속할 수 있습니다.
▶ 재생 위치
재생 위치 리셋DAY VOCA · MY 수업 · 소리영어 · OPIC · FRIENDS에 저장된 전체 재생 위치를 모두 처음으로 되돌립니다.
