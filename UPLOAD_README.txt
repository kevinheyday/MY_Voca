MY ENGLISH V5.3.178
Base: V5.3.177

첫 홈 화면 정상화

문제 원인
- v5.3.177의 마지막 self-heal이 기존 legacy 코드가 먼저 활성화한 탭을 읽어
  첫 홈 화면을 MY 수업으로 다시 바꾸는 경우가 있었음.

수정
- 앱 최초 홈 진입은 무조건 DAY VOCA를 기본값으로 사용.
- legacy active 버튼 상태를 최초 홈 기본값으로 사용하지 않음.
- 초기 DOM 안정화 후 홈이 실제로 보이는 상태일 때 DAY VOCA로 한 번 정규화.
- 다른 상세 화면을 열어둔 경우 강제로 홈으로 끌고 오지 않음.
- Drawer 홈 메뉴도 DAY VOCA 기준 Root Home 유지.
- 사용자가 이후 MY 수업 / 소리영어 / OPIC을 누르면 정상적으로 해당 모드로 전환.

기존 기능 보존
- 3줄 메뉴 안전 레이어
- DAY/MY/SORI/OPIC 학습 엔진
- 단어 퀴즈/단어 비교
- 문장 말하기/음성 녹음
- 전체 재생/무한 반복
