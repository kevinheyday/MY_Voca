말하기 상단 중복 표기 표준화
- MY 수업 / 소리영어 / OPIC 공통 규칙.
- prompt와 pattern이 실질적으로 같은 표현이면 한 번만 표시.
- 이 경우 둥근 pattern chip만 유지하고, 위의 중복 제목(h3)은 숨김.
- prompt와 pattern이 서로 다른 경우에는 둘 다 유지.
- prompt만 있으면 prompt 유지.
- pattern만 있으면 pattern chip 유지.

예:

[look beyond ~]
→ 중복이므로 [look beyond ~] pattern chip만 표시.

- 모든 학습 문장 안의 패턴 색상 구별 (핵심문장 / Chunk 예문 / 말하기)
