MY VOCA V5.3.171
Base: V5.3.170

1차 구조 개편
- Drawer: 홈 → 1. 학습 → 2. 퀴즈 → 3. 문장 말하기 → 기타
- 학습: DAY VOCA / MY 수업 / 소리영어 / OPIC
- 퀴즈: 단어 퀴즈만
- 문장 말하기: 문장 말하기 연습 + 음성 녹음 학습
- 학습 이어서 하기 제거
- 집중 학습 섹션 제거

기능 분리 / 코드 표준화
- 퀴즈에서 문장 말하기 탭을 숨겨 실제 기능도 분리.
- 문장 말하기 메뉴는 기존 검증된 sentence engine을 독립 activity로 재사용.
- 음성 녹음 학습은 기존 독립 화면 유지.
- 문장 말하기와 음성 녹음 학습은 기존 sentenceRecording* 공통 녹음 엔진 사용.
- 동일 기능을 위한 별도 복제 코드는 만들지 않음.

기존 기능 보존
- 객관식/단어 말하기/모르는 단어/유의어·반의어
- 문장 말하기 이어하기
- 녹음/파형/내 녹음/정답 듣기
- DAY/MY/SORI/OPIC 학습
- 전체 시작/정지, 무한 반복
- 패턴 색상/한글 뜻
